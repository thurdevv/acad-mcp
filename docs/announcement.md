## Português (LinkedIn / grupos de AutoCAD)

**Coloquei o Claude para desenhar no AutoCAD — e o código é aberto.**

O acad-mcp é um servidor MCP que conecta o Claude (e outros assistentes compatíveis) ao AutoCAD aberto no seu PC.
Você pede em português e ele desenha, edita, cota, confere padrão de layers e tira quantitativos — direto no
desenho, com um Ctrl+Z por ação.

O que dá para fazer:
• Desenhar e editar a partir de uma descrição ou de um croqui
• Ler desenhos grandes rápido (50 mil entidades em ~15 s)
• Quantitativos e atributos de blocos direto para o Excel
• Conferir e aplicar padrão de layers
• Processar uma pasta inteira de DWGs sem abrir (os originais não são alterados)
• Importar PDF vetorial com as medidas reais e rastrear scans

Requisitos: Windows + AutoCAD completo (não funciona no LT). Testado no AutoCAD 2027.
Código, instalação e limitações: https://github.com/thurdevv/acad-mcp

AutoCAD é marca registrada da Autodesk. Projeto independente, sem vínculo com a Autodesk.

## English (LinkedIn / Reddit / forums)

**I got Claude to draw in AutoCAD — open source.**

acad-mcp is an MCP server that connects Claude (and other MCP clients) to the AutoCAD running on your PC. Ask in
plain language and it draws, edits, dimensions, checks layer standards and does take-offs — right in the drawing,
one undo per action.

• Draw and edit from a description or a sketch
• Read large drawings fast (50k entities in ~15 s)
• Quantities and block attributes straight to CSV/Excel
• Check and apply layer standards
• Batch-process a folder of DWGs without opening them (originals untouched)
• Import vector PDFs at real scale and trace scans

Requirements: Windows + full AutoCAD (not LT). Tested on AutoCAD 2027.
Code, install and limitations: https://github.com/thurdevv/acad-mcp

AutoCAD is a registered trademark of Autodesk, Inc. Independent project, not affiliated with Autodesk.
